## 🔥 What I'm Building

### ☕️ Cafe Ledger (PWA) — *Real-world internal tool*
가족 운영 카페에서 **실제로 사용하는** 예치금/미수금/예약 장부 관리 PWA입니다.  
실사용자인 어머니가 **스마트폰에서 앱처럼 빠르게 기록/조회**할 수 있도록 설계했습니다.

- 모바일 퍼스트 UX: 빠른 입력 흐름, 명확한 네비게이션
- 직원 초대/권한 기반 운영 흐름(역할별 접근/기능 분리)
- 예약 완료 시 장부 자동 반영 등 운영 자동화
- AI Helper(진행 중): 자연어 입력 → **미리보기 → 확인 → 프리필**(안전한 적용 정책)

👉 https://nescafe-admin-pwa.vercel.app/
